Using the dictionary offline

Choose Save offline and wait for “Ready offline”. Downloads can be cancelled and resumed. The browser may refuse persistent storage or later remove saved data; Verify offline copy checks and restores the package when connected. Saving needs free disk space beyond the download size.

On localhost, keep the local server available until saving completes. After that, reopen the same address in the same browser profile. A file opened directly from disk does not support the worker and offline cache.
